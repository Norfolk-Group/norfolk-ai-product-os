# Plans

Plans are time-bounded decision artifacts for proposed or active work. They do not override accepted Product OS contracts, authorize adoption by a product, or grant destructive approval.

Use `YYYY-MM-DD-NNN-type-short-title-plan.md`, record status and owner, cite affected requirements and decisions, and state scope exclusions. Implementation progress belongs in reviewable changes and delivery records; preserve the plan's original decisions unless a new revision explicitly supersedes it.
