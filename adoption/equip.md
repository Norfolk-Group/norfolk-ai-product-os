# Equip workflow

Equip is additive. It resolves repository organization from trusted remote metadata, selects the most restrictive payload for unknown identity, verifies sidecar sensitivity, and plans files. Unchanged managed files update; locally edited managed files become visible conflicts. Unmanaged product files are never claimed by coincidence.

Preflight refuses overlapping Tidy work, target paths changed on another open branch when determinable, dirty/partial state without a matching checkpoint, incompatible versions, and any deletion. The result is a branch/PR proposal with impact, conflicts, exceptions, validation, and rollback; it is not auto-merged.
