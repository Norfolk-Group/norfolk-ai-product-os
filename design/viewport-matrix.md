# Viewport matrix

Every responsive catalog covers named mobile, tablet, and desktop viewports, both relevant orientations, safe areas, keyboard focus, zoom, reduced motion, and long or localized content. Width and height are exact integers; “responsive” or “latest device” is not a comparable baseline. Product contracts may add breakpoints but cannot omit the canonical matrix without an approved exception.
