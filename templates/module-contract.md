# Module name

Declare owner, purpose, lifecycle status, compatible Product OS/Kit versions, dependencies, configuration, secret names, procedures, transport map, authorization, approvals, schema/migrations, data lifecycle, UI and accessibility contract, telemetry/redaction, failure recovery, tests, enable/disable behavior, upgrade, rollback, and verified removal.

List product extension points and forbidden overrides. Attach evidence and provenance for any product- or client-derived behavior. Name the accepted decision for any additional foundational dependency.
