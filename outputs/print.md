# Print

Print contracts declare trim size, bleed, safe area, margins, color space, profile, ink/contrast constraints, image resolution, overprint, crop marks, binding allowance, duplex behavior, paper assumption, and proof method. Typography respects the PDF floor. Web screenshots and unverified RGB-to-CMYK conversions are not print masters. Large masters live in versioned R2 storage with a lightweight manifest and proof fixture in Git.
