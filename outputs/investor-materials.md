# Investor materials

Every displayed number ties exactly to the authoritative snapshot under the declared currency, timezone, period, precision, and rounding policy. Derived values record formula/calculation version. Totals, subtotals, percentages, comparatives, and footnotes reconcile before visual approval. Data freshness, estimates, exclusions, forward-looking statements, confidentiality, and source disclosures are visible. A visually correct file with a numerical mismatch fails release.

Investor outputs require an independent calculation review and a separate design review. Neither substitutes for recipient authorization or legal/compliance approval where applicable.
