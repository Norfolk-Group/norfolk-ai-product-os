# Norfolk Manual pinned content audit

Repository: `Norfolk-Group/norfolk-manual` (private, active, default branch `main`). GitHub MCP observed `main`, `test/kit-guard-proof`, and `deletions/animation-library`. This evidence is Norfolk-only and cannot be published.

The README proposes a rendered Manual derived from Kit, but the repository does not contain a functioning renderer. Its substantial content is a duplicated July 2026 Kit payload. The named CONTRACT pages for architecture, design system, security, and business logic are empty or skeletal. The animation library is copied from an older H+ implementation and carries stale product/persona coupling; branch `deletions/animation-library` exists specifically to remove it. Setup, launcher, and kit-guard utilities do not establish a unique current governance source.

No unique current doctrine was found. The resulting proposal is to promote nothing from Manual, preserve all repository evidence, use the Product OS generated handbook as the human-readable view, keep current executable behavior in Kit, and delete Manual only after the retirement dossier passes and exact approval is received.
