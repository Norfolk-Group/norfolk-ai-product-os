# Living visual catalogs

The private Product OS catalog presents abstract standards; Norfolk Kit presents executable specimens generated from real components, tokens, registries, routes, and icons. Neither output is an editable second source of doctrine.

Every generated page must be self-contained, work from local files without a server or network request, and expose the Product OS and Kit versions, normalized source hashes, source paths, freshness, and approval status. A source change without regeneration fails CI.

Product OS publishes a handbook and abstract design catalog. Kit publishes `components.html`, `motion.html`, `icons.html`, `architecture.html`, and `navigation.html`. Client data and branding are excluded unless an approved, sanitized evidence record explicitly permits reuse.
